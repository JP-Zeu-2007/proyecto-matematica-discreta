3. Guía de Uso Detallada (¿Qué hace cada botón?)

3.1 Barra de Herramientas Superior (El Constructor)

Avatar (Persona / Carro / Avión)

Algoritmo: Animación Visual.

Explicación: Cuando presionas un botón de Euler, Hamilton o Dijkstra, este avatar (un pequeño ícono) viajará físicamente por las aristas del grafo mostrando el camino exacto paso a paso.

Ejemplo: Si haces un ciclo, verás al avatar "caminando" de nodo en nodo.

+ Vértice

Algoritmo: Creación de Nodos.

Explicación: Crea un punto en el lienzo. Puedes elegir su forma (Círculo, Avión, Edificio, Montaña).

Ejemplo: Si estás simulando vuelos, eliges el ícono de avión y creas "Guatemala", "Miami", etc.

Tijera

Algoritmo: Eliminación.

Explicación: Corta (elimina) una arista.

Ejemplo: Si A y B están conectados, presionas la tijera y haces clic sobre la línea; la conexión desaparece y los grados de A y B bajan en 1.

1. Evaluar Conexidad (DFS)

¿Cómo funciona en código? Usa una pila (Stack) para recorrer el grafo. Marca los nodos visitados. Si al final el número de visitados es igual al total de nodos, el grafo es Conexo (se pinta verde). Si no, es Desconexo (se pinta rojo) y avisa que no hay Euler/Hamilton.

// Pseudocódigo DFS (Búsqueda en Profundidad)
function esConexo(grafo):
  visitados = nuevo Set()
  pila = [nodoInicial]
  while pila no esté vacía:
    nodo = pila.pop()
    if nodo no está en visitados:
      visitados.add(nodo)
      para cada vecino de nodo:
        pila.push(vecino)
  return visitados.size == grafo.numNodos()

Ejemplo: Nodos [A, B, C] con aristas A-B, B-C. DFS empieza en A, va a B, luego a C. Visitó 3 de 3. ✅ Conexo. Pero si C está aislado, solo visitará 2 de 3. ❌ Desconexo.

2. Camino de Euler (Amarillo)

¿Cómo funciona en código? Usa el algoritmo de Hierholzer. Busca un nodo con aristas, se mueve por ellas borrándolas temporalmente y guarda el recorrido. Al final lo invierte.

Condición Matemática: Solo se activa si hay 0 o 2 nodos con grado impar.

Grado Par (0, 2, 4...) Grado Impar (1, 3, 5...)
// Algoritmo de Hierholzer (Camino de Euler)
function caminoEuler(grafo):
  impar = nodos con grado % 2 != 0
  if impar.length > 2: return null // Imposible
  inicio = impar.length == 0 ? nodoCualquiera : impar[0]
  camino = []
  pila = [inicio]
  while pila no esté vacía:
    nodo = pila.peek()
    if nodo tiene aristas:
      vecino = arista.tomarUna()
      eliminarArista(nodo, vecino) // temporal
      pila.push(vecino)
    else:
      camino.push(pila.pop())
  return camino.reverse()

Ejemplo: Un sobre abierto (A-B-C-A, A-D). Los nodos B y D tienen grado 1 (impares). El camino empieza en B, pasa por todo y termina en D.

B y D son impares → Camino de Euler válido: B→A→C→D (o B→A→D→C)

3. Ciclo de Euler (Morado)

¿Cómo funciona en código? Igual que Hierholzer, pero el nodo de inicio debe ser el mismo que el de fin. Al terminar, hace un "pulso" verde en el nodo de origen para confirmar que se cerró el círculo.

Condición Matemática: TODOS los nodos deben tener grado par.

Todos grado par ✅ Algún impar ❌
// Ciclo de Euler (variante de Hierholzer)
function cicloEuler(grafo):
  for nodo in grafo.nodos:
    if grado(nodo) % 2 != 0:
      return null // No es ciclo
  inicio = grafo.nodos[0]
  camino = hierholzer(grafo, inicio)
  if camino[0] == camino[camino.length-1]:
    animarPulsoVerde(inicio) // Confirmar cierre
  return camino

Ejemplo: Un cuadrado (A-B-C-D-A). Todos tienen grado 2. La animación empieza en A y termina en A.

Todos grado 2 → Ciclo: A→B→C→D→A ✅

4. Camino y Ciclo de Hamilton (Verde)

¿Cómo funciona en código? Usa Backtracking (Vuelta Atrás). Es como un laberinto: avanza y marca visitados. Si se atora, retrocede, borra la marca y prueba otro camino. Debido a esto, el código calcula el tiempo (en milisegundos) y los intentos.

// Backtracking para Hamilton
function hamilton(grafo, actual, visitados, camino):
  if camino.length == grafo.numNodos:
    if hayArista(actual, camino[0]): return camino // Ciclo
    return camino // Camino
  for vecino de actual:
    if vecino no está en visitados:
      intentos++
      visitados.add(vecino)
      camino.push(vecino)
      resultado = hamilton(grafo, vecino, visitados, camino)
      if resultado: return resultado
      camino.pop() // Retroceder
      visitados.delete(vecino)
  return null

Ejemplo: Un grafo con un centro y 3 hojas. No hay Hamilton porque para visitar todas las hojas tendrías que pasar por el centro más de una vez (violando la regla de visitar cada nodo 1 sola vez).

Centro C con 3 hojas → No existe camino hamiltoniano

5. Dijkstra (Azul)

¿Cómo funciona en código? Usa una "Cola de Prioridad". Siempre elige el camino con el peso acumulado más bajo. Prohíbe pesos negativos (el sistema te bloquea si intentas poner -5). Al final, pinta la ruta óptima y llena una tabla con TODAS las rutas posibles.

Restricción: Todos los pesos deben ser ≥ 0.

Peso ≥ 0 ✅ Peso negativo ❌ Bloqueado
// Dijkstra con Cola de Prioridad
function dijkstra(grafo, origen, destino):
  distancias = {} // ∞ para todos
  distancias[origen] = 0
  cola = MinHeap([( 0, origen )])
  previos = {}
  while cola no esté vacía:
    (dist, nodo) = cola.extraerMin()
    if nodo == destino: break
    for (vecino, peso) de nodo.aristas:
      if peso < 0: throw // Bloqueado
      nuevaDist = dist + peso
      if nuevaDist < distancias[vecino]:
        distancias[vecino] = nuevaDist
        previos[vecino] = nodo
        cola.insertar(nuevaDist, vecino)
  return reconstruirRuta(previos, destino)

Ejemplo: A conecta a B (10 km) y a C (50 km). B conecta a C (5 km). Dijkstra no irá directo de A a C (50 km), sino que irá A→B→C (15 km) porque es más barato.

Ruta óptima A→B→C: 10 + 5 = 15 km (verde) vs. A→C directo: 50 km

5. Preguntas Frecuentes (FAQ)

¿Qué significan los colores de los nodos?

Borde Dorado indica Grado Par. Borde Rojo indica Grado Impar. Borde Verde Punteado indica Nodo "Usado".

¿Por qué no me deja calcular el Camino de Euler?

Revisa el panel de Grados. Necesitas exactamente 2 vértices impares (o 0). Si tienes 4 o más, es imposible.

¿Por qué el Ciclo de Euler me sale bloqueado?

El Ciclo exige que TODOS los vértices tengan grado Par. Si tan solo uno es impar, no se puede cerrar.

¿Puedo usar pesos negativos en Dijkstra?

No. El sistema bloquea los pesos negativos. El algoritmo voraz no funciona con ellos porque entraría en un bucle infinito.

¿Los grafos se borran si cierro la página?

No, si usas el botón azul de "Guardar", se quedan en el LocalStorage de tu navegador.
