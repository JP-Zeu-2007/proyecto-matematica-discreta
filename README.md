# Proyecto Final - Matemática Discreta UMG

Este es el repositorio oficial del proyecto.

## 🛠️ Herramientas necesarias
- Visual Studio Code
- Git
- Cuenta de GitHub

## 📁 Estructura del proyecto
- `/css`: Estilos.
- `/js`: Lógica de los módulos (main, graph, validations, euler, hamilton, dijkstra).
- `/libs`: Librerías locales para la versión offline.

## 🚀 Cómo empezar
1. Clona este repositorio: `git clone [enlace]`
2. Abre `index.html` en tu navegador o usa Live Server.
3. Si eres el Integrante 2, 3 o 4, revisa tu archivo asignado en la carpeta correspondiente.
